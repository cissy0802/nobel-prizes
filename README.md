# 诺奖精读 · Nobel Prizes, Explained

每期讲透一个诺贝尔奖，写成轻科普：它发现了什么、对普通人意味着什么、和别的学科有什么相通之处。

→ **<https://hub.cissychen.com/nobel-prizes/>**

- 范围：2020–2026 年的物理、化学、生理学或医学、经济学、文学奖（和平奖不收），共 35 期，一个奖一页。
- 节奏：云端 routine 每日一期，严格按 `TOPICS.md` 顺序。存量写完后自动停；每年 10 月颁奖后由本地任务 `nobel-annual-refill` 追加新一届的五条，守卫 `verify-routine-caps` 会把 routine 重新打开。
- 事实底座：nobelprize.org 官方 API、Popular information、Advanced information，加上突破性论文的原文。
- 引擎说明见 `CLAUDE.md`，页面骨架见 `TEMPLATE.html`。
